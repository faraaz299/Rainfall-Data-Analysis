# Rainfall Data Analysis

## 📌 Project Overview

This project analyzes rainfall data using Python and Pandas.
The analysis focuses on understanding rainfall patterns and the
relationship between rainfall and different weather conditions.

## 🛠️ Technologies Used

- Python
- Pandas
- Jupyter Notebook / Google Colab

## 📂 Files in this Repository

- `Pandas_Environmental_Data_.ipynb` - Jupyter Notebook containing the complete data analysis.
- `Rainfall.csv` - Dataset used for the analysis.
- `README.md` - Project documentation.

## 🔍 Analysis Performed

The project includes:

- Loading and exploring the rainfall dataset
- Checking dataset size, shape, columns, and data types
- Cleaning column names
- Checking and handling missing values
- Checking duplicate records
- Generating statistical summaries
- Calculating rainfall counts and percentages
- Comparing rainy and non-rainy days
- Finding maximum and minimum temperatures
- Finding the 10 hottest and 10 coldest days
- Performing correlation analysis
- Comparing weather conditions on rainy and non-rainy days

## 🌧️ Key Findings

The analysis shows differences between rainy and non-rainy days.

Rainy days tend to have:

- Higher humidity
- More cloud cover
- Higher windspeed
- Less sunshine
- Slightly lower temperature
- Slightly lower atmospheric pressure

## 📊 Dataset Information

The dataset contains **366 rows and 12 columns**.

The main weather attributes include:

- Day
- Pressure
- Maximum Temperature
- Temperature
- Minimum Temperature
- Dew Point
- Humidity
- Cloud Cover
- Rainfall
- Sunshine
- Wind Direction
- Windspeed

## 🚀 How to Run

1. Download or clone this repository.
2. Open `Pandas_Environmental_Data_.ipynb` in Google Colab or Jupyter Notebook.
3. Keep `Rainfall.csv` in the same directory.
4. Run the notebook cells sequentially.
